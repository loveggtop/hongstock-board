⌨️ Windows 키보드를 Mac에 연결했을 때 키 대응

Mac 전용 키보드 없이 Windows 키보드를 그대로 Mac에 연결해서 사용할 때의 핵심 정보입니다.

💡 가장 중요한 포인트: Mac의 Command(⌘) = Windows 키보드의 Windows 키(⊞)
Mac 키보드 키기호Windows 키보드의 해당 키위치 힌트
Command⌘Windows 키 (⊞)스페이스바 왼쪽/오른쪽
Option⌥Alt 키Windows 키 옆
Control⌃Ctrl 키왼쪽 하단 모서리
Delete (←)⌫Backspace백스페이스
Forward Delete⌦DeleteBackspace 오른쪽 별도 키
Return↩Enter같은 위치
⚠️ 주의: Windows 키보드에서 Ctrl ≠ Command 입니다! Mac의 Command 역할을 하는 건 Ctrl이 아니라 Windows 키(⊞)입니다.

⚙️ Windows 키보드 키 배열 커스터마이징

Mac에서 Windows 키보드의 키 배열을 바꾸고 싶다면:
시스템 설정 → 키보드 → 키보드 단축키 → 보조 키에서 변경 가능합니다.
