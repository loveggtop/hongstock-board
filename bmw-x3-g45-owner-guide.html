세대를 먼저 확인하세요

이 가이드는 2024년 11월 국내 출시된 4세대 신형 X3(코드네임 G45) 기준입니다. 2024년 이전 3세대 X3(G01)는 iDrive 7을 쓰기 때문에 메뉴 구조와 버튼 배치가 전혀 다릅니다. 인터넷에서 'BMW X3 사용법'을 검색하면 대부분 구형 자료가 나오므로 그대로 따라 하시면 안 됩니다.

최종 기준은 차 안에 있습니다

차량마다 트림·옵션·소프트웨어 버전에 따라 없는 기능이 있을 수 있습니다. 최종 확인은 반드시 차량 안 iDrive의 취급설명서 앱에서 하세요. 그 설명서만이 내 차 차대번호(VIN) 기준 실제 사양을 반영합니다.

01공식 매뉴얼을 보는 4가지 방법

아래로 갈수록 접근성은 좋아지지만 정확도는 떨어집니다. ①번이 가장 정확합니다.

① 차량 안 iDrive 취급설명서 — 가장 정확

All Apps›취급설명서 (Owner's Handbook)
  • 내 차 VIN 기준으로 실제 장착된 사양만 보여줍니다. 옵션 유무 논쟁이 생기면 여기가 정답입니다.
  • 검색창에 '시트 열선', '어시스턴트' 같은 키워드를 넣으면 해당 항목으로 바로 이동합니다.

② My BMW 앱 안의 디지털 매뉴얼

  • 차량 등록을 끝내면 앱 안에서 매뉴얼을 볼 수 있습니다. 차 밖에서 찾아볼 때 편합니다.

③ BMW 드라이버 가이드 앱

  • iOS / 안드로이드 앱스토어에서 무료. 차대번호를 넣으면 내 차 전용 설명서가 내려받아집니다.
  • 안내 페이지: bmw.co.kr › 오너 › 온라인 매뉴얼

④ 온라인 보조 자료 (비공식이지만 검색이 편함)

  • BMW USA 공식 FAQ — faq.bmwusa.com 에서 X3 from 08/2024로 검색하면 G45 전용 기능 설명이 항목별로 나옵니다. 영문이지만 우리 차와 같은 세대입니다.
  • G45 온라인 오너스 매뉴얼 — mycarusermanual.com (비공식 정리본, 영문)
차대번호(VIN)는 어디서 확인하나

자동차등록증 / 운전석 도어를 열었을 때 B필러 스티커 / 앞유리 하단 좌측 표시. 17자리입니다.

My BMW 앱에 차를 등록할 때는 컨트롤 디스플레이에 뜨는 QR 코드를 앱으로 찍는 방식이 가장 빠릅니다.

02인수 첫 주에 꼭 해둘 10가지

아래만 끝내두면 이후 운전 중에 화면을 뒤질 일이 크게 줄어듭니다.

  1. My BMW 앱 설치 + 차량 등록앱 로그인 상태에서 컨트롤 디스플레이의 QR 코드를 스캔. 원격 도어 잠금, 차량 위치 찾기, 목적지 전송이 전부 여기서 열립니다.
  2. BMW ID로 차량 로그인시트 포지션·공조·내비 즐겨찾기·화면 설정이 클라우드에 저장됩니다. 차량당 최대 7개 프로필.
  3. 디지털 키 플러스 등록국내 X3 전 모델 기본. 아이폰은 Apple 지갑, 갤럭시는 Samsung Pass에 저장됩니다.
  4. 무선 카플레이 / 안드로이드 오토 페어링최초 1회만 설정하면 이후 자동 연결. 절차는 4장 참고.
  5. 시트 메모리 저장운전석 도어의 SET 버튼 → 불이 켜진 동안 1 또는 2를 누름. 미러 각도와 HUD 높이까지 같이 저장됩니다.
  6. 헤드업 디스플레이 높이 맞추기스티어링 휠 설정 버튼 → 메뉴에서 HEAD-UP 선택 → 널링 휠로 조절.
  7. 파노라마 뷰 자동 켜짐 지점 저장집·회사 주차장 입구에서 저장해두면 매번 버튼을 누르지 않아도 카메라가 자동으로 켜집니다. 최대 10곳.
  8. 주행보조 경고 민감도 조정차선이탈 진동·하차 경고음이 거슬리면 5-3의 메뉴 경로대로 개별 조정.
  9. 무선 소프트웨어 업데이트 확인All Apps → 시스템 설정 → 리모트 소프트웨어 업그레이드 → 업그레이드 검색.
  10. 커넥티드드라이브 스토어 로그인BMW ID로 로그인해야 내 차에 적용 가능한 서비스와 무료 체험 기간이 표시됩니다.

03기본 조작 — 공조 · 시트 · 운전자세 · 기어

먼저 알아야 할 G45의 성격

신형 X3는 물리 버튼을 줄였지만 전부 없앤 것은 아닙니다. iDrive 로터리 컨트롤러(다이얼)는 그대로 남아 있습니다. 이 점이 X1·X2와 다르고, 신형 BMW 중 다이얼과 iDrive 9를 함께 쓰는 첫 차입니다.

남아 있는 물리 조작부 — 비상등 · 볼륨 · 곡 넘김 · 앞유리 성에 제거 · 뒷유리 열선 · My Modes · iDrive 다이얼 · 주차 지원 · 오토홀드 · 전자식 주차 브레이크 · 기어 토글 · 시동 버튼

화면으로 옮겨간 것 — 온도 · 풍량 · 풍향 · 시트 열선 · 시트 통풍 · 스티어링 휠 열선 (구형 X3에서 물리 버튼이던 항목들)

3-1. 공조

기본 조작은 화면 맨 아래에 항상 떠 있는 클라이밋 바에서 합니다. 온도는 하단의 + / − 를 그냥 누르면 됩니다.

음성이 더 빠른 경우

3-2. 송풍구 — 도어에도 있습니다

  • 앞좌석 — 풍향은 손으로, 풍량은 슬라이더로 조절
  • 도어 트림 송풍구 — 도어 패널의 조작 클러스터에 햅틱 슬라이더가 있어 도어 송풍구 풍량을 조절합니다. 신형에서 추가된 부분이라 처음엔 잘 못 찾습니다.
  • 뒷좌석 — 요철 다이얼로 개폐

3-3. 인터랙션 스마트 바

대시보드를 가로지르는 유리 느낌의 조명 패널입니다. 조명만 하는 게 아니라 터치 조작부이기도 합니다.

  • 가능한 터치 조작 — 통합 송풍구 풍량, 앞유리 성에 제거, 뒷유리 열선, 비상등
  • 조명 색상은 앰비언트 라이트 옵션 장착 시 15가지. 선택한 My Mode에 따라 자동으로 바뀝니다.
  • 색을 직접 고르려면 Personal 모드로 먼저 전환한 뒤 아래 경로로 들어갑니다. 다른 모드에서는 선택이 잠겨 있습니다.
All Apps›차량›실내 조명›앰비언트 라이팅›색상
  • 도어를 열 때 뒤에서 차량·자전거가 접근하면 바가 붉게 점멸하는 연출은 같은 메뉴의 Lighting effects에서 켜고 끕니다.
글로브박스는 인터랙션 바로 열지 않습니다

글로브박스에 달린 물리 버튼을 누르세요. 터치로 여는 것은 7시리즈 계열입니다.

3-4. 시트와 운전자세

전동시트 스위치는 도어가 아니라 시트 옆면에 있습니다

조절방법
앞뒤 / 높이 / 등받이시트 측면 스위치를 해당 방향으로 밀거나 젖힘
시트 방석 기울기틸트 스위치를 위·아래로
럼버 서포트럼버 버튼을 앞뒤(볼륨) · 위아래(위치)
등받이 폭 (M/스포츠 시트)앞쪽 버튼 = 좁게 / 뒤쪽 버튼 = 넓게
허벅지 서포트전동이 아니라 수동입니다. 시트 앞쪽 레버를 당긴 채로 밀고 당깁니다
헤드레스트등받이의 릴리스 버튼을 누르고 내림. 올릴 때는 그냥 위로 (수동)

메모리 시트 — 버튼은 운전석 도어 트림

  1. 운전석 도어의 SET 버튼을 누른다 → LED가 켜진다
  2. LED가 켜져 있는 동안 메모리 1 또는 2 버튼을 누른다
  3. 불러올 때는 1 또는 2를 그냥 누른다

함께 저장되는 항목 — 시트 포지션, 사이드미러 각도, 럼버 서포트 위치, 헤드업 디스플레이 높이

사이드미러

  • 조절 버튼은 운전석 도어 트림. 좌/우 선택 후 버튼을 움직이는 방향대로 움직입니다.
  • 후진 시 자동 하향은 조수석 미러만 내려갑니다. 운전석 미러가 안 내려간다고 고장이 아닙니다.

스티어링 휠 · 헤드업 디스플레이

  • 스티어링 휠 조절 — 칼럼의 릴리스 레버를 끝까지 아래로 누르고 양손으로 잡아 조절 후 레버 원위치 (수동식 기준)
  • HUD 켜고 끄기 — All Apps › 차량 › 디스플레이 › 헤드업 디스플레이
  • HUD 높이·회전·밝기 — 스티어링 휠의 설정 버튼 → 메뉴에서 HEAD-UP 선택 → 널링 휠로 조절

3-5. 기어 토글과 주행 조작

신형은 스틱형 레버가 사라지고 완전 전자식 토글 스위치로 바뀌었습니다.

  1. 브레이크 페달을 밟는다
  2. 시동을 켠다
  3. 토글을 원하는 방향으로 젖히거나 당긴다 — 필요하면 저항점을 넘겨서 끝까지
  4. 토글은 자동으로 가운데로 돌아온다
항목내용
기어 포지션P / R / N / D / S 다섯 개가 전부입니다. B 모드(회생제동 단계)는 없습니다
P별도의 P 버튼으로 조작. 시동을 끄면 자동으로 P가 걸립니다
S스포츠 프로그램. S에서 패들을 당기면 수동 모드 M이 계속 유지됩니다
패들 시프트D에서 당기면 일시적 수동(D1, D2… 표시), 잠시 뒤 자동 복귀 / S에서 당기면 상시 수동
오토홀드센터 콘솔 버튼. 켜면 정차 시 자동으로 잡아주고, 가속 페달을 밟으면 풀립니다. 오토홀드로 정차 중 시동을 끄면 주차 브레이크가 자동 체결됩니다
전자식 주차 브레이크센터 콘솔. 체결은 버튼을 누름(press), 수동 해제는 브레이크를 밟은 채 버튼을 밈(push). 주행 중 길게 누르고 있으면 비상 제동
회생제동48V 마일드 하이브리드가 감속 시 자동 회수합니다. 사용자가 단계를 고르는 UI는 없습니다

오토 스타트/스톱이 안 걸릴 때

  • Sport 또는 Sport Plus 모드이거나 기어가 S일 때는 의도적으로 꺼집니다. 고장이 아닙니다.
  • 수동으로 켜고 끄기 — All Apps › 차량 › 주행 설정 › 드라이브트레인 & 섀시 › 오토 스타트/스톱

3-6. My Modes (주행 · 실내 분위기 모드)

4-1. 화면 구성

4-3. 무선 애플 카플레이 연결

국내 X3는 무선 카플레이·무선 안드로이드 오토가 기본입니다. 케이블이 필요 없습니다.

  1. 차량: All Apps › Apple CarPlay 선택
  2. 아이폰: 설정 › 일반 › CarPlay
  3. 차량이 기기를 찾으면 목록에서 내 아이폰 선택
  4. 차량 화면과 아이폰에 뜬 코드가 같은지 확인 → Pair
  5. '허용' 선택 (차량 데이터 공유 동의)
  6. Siri 설정을 마치면 핸즈프리 호출까지 됩니다
전제조건

아이폰의 데이터 · Siri · Wi-Fi · 블루투스가 모두 켜져 있어야 합니다. 무선 카플레이는 블루투스로 연결을 시작해 Wi-Fi로 넘어가는 구조라 Wi-Fi를 꺼두면 붙지 않습니다.

4-4. 무선 안드로이드 오토 연결

  1. All Apps › Android Auto › Connect phone
  2. 폰 블루투스를 켜고 목록에서 기기 선택
  3. 차량과 폰에 뜬 코드가 같은지 확인
  4. 차량 화면에서 Start Android Auto
  5. 공유할 차량 데이터를 고르고 폰에서 약관 동의

요구사항 — 안드로이드 11 이상, 데이터 요금제, 최초 연결은 P단 정차 상태에서.

4-5. 폰을 두 대 이상 쓸 때 / 연결이 안 될 때

  • 등록 기기 목록 — All Apps › Mobile Devices › MY DEVICES
  • 폰 전환 — 목록에서 MODE 아래의 카플레이·안드로이드 오토 아이콘을 탭하면 현재 기기의 연결이 풀리고 다른 폰으로 넘어갑니다.
  • 기기 삭제 — 기기 이름을 탭 → 연결 해제 또는 Remove
연결이 안 될 때 순서대로 해보세요
  1. 폰 OS를 최신으로 업데이트
  2. 폰의 블루투스와 Wi-Fi를 모두 켜기 (무선 카플레이는 Wi-Fi 필수)
  3. 다른 폰이 먼저 자동 연결되어 있지 않은지 확인 — 이게 원인인 경우가 가장 많습니다
  4. 아이폰 설정 → 일반 → CarPlay에서 해당 차량을 삭제한 뒤 다시 페어링
  5. 차량 쪽 Mobile Devices에서도 기기를 Remove하고 재등록
  6. 그래도 안 되면 볼륨 노브를 20~30초 길게 눌러 iDrive 재부팅

4-6. 음성 명령

  • 호출어는 "안녕 BMW" (영문 설정에서는 Hey BMW). 국내 X3는 라이브 콕핏 프로페셔널이 전 모델 기본이라 한국어 음성 제어가 됩니다.
  • 실제로 잘 되는 명령 — "시트 열선 켜줘", "너무 추워", "○○한테 전화 걸어줘", "집으로 가는 길 안내해줘", "창문 열어줘"
  • 조수석에서 말한 것도 구분해서 인식합니다 (조수석 열선만 켜기 등)
  • 인식률을 올리려면 설정 › 어시스턴트에서 온라인 음성 처리를 켜세요. 체감 차이가 큽니다.

4-7. 내비게이션 — 국내 X3의 가장 큰 장점

국내 판매 X3의 순정 내비는 TMAP 기반 한국형 BMW 내비게이션입니다. 해외 사양과 다릅니다.

  • 온라인 스트리밍 지도라서 지도 업데이트를 따로 할 필요가 없습니다
  • 실시간 교통정보는 티맵 데이터 기반
  • 헤드업 디스플레이와 계기판에 턴바이턴 안내가 뜹니다
  • 증강현실(AR) 뷰 지원 — 실시간 영상 위에 화살표를 겹쳐 보여줍니다
  • My BMW 앱에서 목적지를 차로 전송할 수 있습니다
티맵 앱을 카플레이로 쓸 수도 있지만

카플레이로 실행한 티맵·카카오내비·네이버지도는 헤드업 디스플레이와 계기판에 안내가 뜨지 않습니다. HUD를 쓰려면 순정 내비를 쓰셔야 합니다. 순정 내비 자체가 티맵 기반이라 길안내 품질 차이도 크지 않습니다.

4-9. 디지털 키 플러스

국내 X3 전 모델 기본입니다. 폰을 도어 핸들에 대지 않고 주머니에 넣은 채로 접근·이탈만으로 열리고 잠깁니다.

  1. My BMW 앱에서 차량 등록을 마친다
  2. 앱에서 디지털 키 타일 → SET UP DIGITAL KEY
  3. 물리 키 2개(또는 키 1개 + 셋업 카드)를 차 안에 둔다 → 페어링 시작
  4. 아이폰은 Apple 지갑, 갤럭시는 Samsung Pass, 픽셀은 홈 화면에 키가 생성됩니다
  • 키 공유 — 지갑에서 키 → 공유 → 메시지로 링크 전송. 받는 사람은 BMW ID가 없어도 됩니다. 최대 18명.
  • 공유 제한은 보내기 전에 설정해야 합니다. 사용 시간대, 지역, 최고 속도 제한을 걸 수 있습니다.
  • 아이폰은 배터리가 방전돼도 최대 5시간 동안 잠금해제·시동이 됩니다 (익스프레스 모드)

  • 다운로드는 차량 내장 SIM 또는 My BMW 앱(폰 데이터)으로 받아 차에 전송
  • 설치 조건 — 안전한 곳에 주차, 기어 P, 시동 OFF, 창문·선루프 전부 닫힘, 외기온 영하 10도 이상, 배터리 충분
  • 소요 시간 약 20~30분. 설치 중에는 차를 쓸 수 없고 중단할 수 없습니다. 타이머 예약을 권합니다.

05주행보조와 주차

국내 X3는 해외보다 사양이 좋습니다

국내는 전 트림에 드라이빙 어시스턴트 프로페셔널과 파킹 어시스턴트 플러스(서라운드 뷰 + 후진 어시스턴트)가 기본입니다. 유럽 기본형은 경고 위주 패키지만 들어가고 상당수가 옵션입니다.

다만 최대 200m 자동 주차와 스마트폰 원격 주차가 되는 파킹 어시스턴트 프로페셔널은 국내에서 M50 전용입니다.

5-1. 어댑티브 크루즈 컨트롤 (스톱앤고 포함)

버튼은 스티어링 휠 왼쪽 스포크에 모여 있습니다.

  1. 크루즈 버튼을 눌러 대기 상태로 만든다
  2. 좌측 로커 스위치로 속도를 맞추고 SET을 눌러 저장한다
  3. 거리 버튼으로 차간거리를 4단계 중에서 고른다
  4. 해제는 CNCL 또는 브레이크, 저장 속도 복귀는 RES
조작 요령내용
속도 미세 조정걸림(저항점) 전까지만 살짝 누르면 1km/h 단위
속도 크게 조정저항점을 넘겨 누르면 최대 10km/h 단위
현재 속도로 저장저항점에서 계속 누르고 있으면 페달 없이 가감속되고, 떼는 순간 그 속도가 저장됩니다
정차 후 재출발짧은 정차는 앞차 출발 시 자동. 오래 서 있었으면 RES를 누르거나 가속 페달을 살짝 밟습니다
정체 구간 요령정차 중에 미리 RES를 눌러두면 앞차가 출발할 때 자동으로 따라 갑니다
차간거리 실사용국내 고속도로에서 4단계(최대)로 두면 끼어들기가 잦습니다. 2~3단계가 현실적입니다
All Apps›차량›주행 설정›주행 보조›주행›거리 제어

5-2. 차선유지 / 어시스티드 드라이빙 모드

  1. 주행 중 스티어링 휠 좌측의 I/O 버튼을 누른다
  2. 필요하면 MODE 버튼으로 계기판 툴바에 '어시스티드 드라이빙 모드'를 띄운다
  3. 조건이 맞으면 자동으로 개입이 시작된다
  • 아이콘 색으로 상태를 봅니다. 회색 = 준비만 된 상태(개입 안 함) / 초록색 = 지금 차선유지 개입 중
  • 국내 X3는 핸즈오프(손 떼고 주행)가 되지 않습니다. BMW의 핸즈프리 기능인 하이웨이 어시스턴트는 5·7시리즈, iX, X5/X6/X7 등에만 적용되고 승인 국가에도 한국은 없습니다. 손을 대고 계셔야 합니다.
  • 손을 떼면 경고 → 강한 인수 요구 → 비상정지 어시스턴트 순서로 진행됩니다.
  • 급커브나 국도·산길에서는 스티어링 어시스트가 스스로 해제되는 경우가 흔합니다. 정상 동작 범위입니다.

5-4. 제한속도 표지판 인식

주행 보조›주행›Speed Limit Assistance›Speed limits
  • Adjust manually — 감지된 제한속도를 SET 버튼으로 직접 적용
  • Show anticipation — 현재와 예상 제한속도만 표시
  • Show current limit — 현재 제한속도만 표시
  • Off — 끔
  • 허용치(오프셋)도 설정할 수 있습니다. 전 구간 공통 오프셋과, 60km/h 이하 구간에만 적용하는 별도 오프셋이 따로 있습니다.
이 기능은 시동을 끄면 꺼집니다

제한속도 어시스트는 엔진을 끄면 자동으로 비활성화됩니다. 매번 다시 켜야 합니다. 이 외에 ACC를 켜거나 주행 모드를 바꿀 때도 해제됩니다.

5-5. 자동 주차

  1. 센터 콘솔의 파킹 어시스턴트 버튼을 누른다
  2. 천천히 주행한다 — 최대 약 35km/h까지 주차 공간을 스캔합니다
  3. 공간을 찾으면 알림음과 함께 화면에 평행 / 직각 / 사선 선택지가 뜬다
  4. 완전히 정차한 뒤 원하는 방식을 확정한다
  5. 차가 스티어링·가속·제동·변속을 모두 알아서 합니다
  6. 완료되면 자동으로 P단으로 바뀝니다
  • 안전벨트를 매고 있어야 작동합니다. 벨트를 풀면 중단됩니다.
  • 국내 20 트림 기준으로는 앞뒤에 차가 있는 일반적인 빈 공간을 인식합니다. 주차선·연석만 보고 자리를 잡는 기능은 M50의 프로페셔널 사양입니다.

5-6. 서라운드 뷰 (파노라마 뷰)

  • 켜기 — 화면 또는 콘솔의 파노라마 뷰 버튼. 나가려면 왼쪽 툴바에서 다른 카메라 뷰를 고릅니다.
  • 주차 뷰는 장애물을 초록·노랑·빨강 타일로 표시합니다.
가장 저평가된 기능 — 자동 켜짐 지점 저장

집이나 회사 주차장 입구처럼 늘 카메라를 켜는 자리를 GPS로 저장해두면, 다음부터는 버튼을 누르지 않아도 자동으로 화면이 뜹니다. 최대 10곳.

저장 방법 — 원하는 위치에 정차 → 파킹 어시스턴트 버튼 → Panorama view → Activation point → Save activation point

켜고 끄기 — 주행 보조 → 주차 → GPS-based

주의

파노라마 영상은 일부 영역에 왜곡이 있어 정확한 거리 판단용이 아닙니다. BMW가 매뉴얼에 명시한 경고입니다. 좁은 곳에서는 눈으로 한 번 더 확인하세요.

5-7. 후진 어시스턴트

들어온 길을 그대로 최대 50m 되짚어 나가는 기능입니다. 좁은 골목이나 막다른 주차장 진입로에서 유용합니다.

  1. 정차한 상태에서 R단을 넣거나 파킹 어시스턴트 버튼을 누른다
  2. 메뉴에서 후진 어시스턴트를 선택한다
  3. 스티어링 휠에서 손을 뗀다 — 조향은 차가 합니다
  4. 가속·제동 페달만 조작한다
  5. 저장 경로 끝에 다다르면 차가 알려주고 조작을 넘겨줍니다

정차 상태여야 메뉴가 뜹니다. 굴러가는 상태에서는 나오지 않습니다.

06자주 막히는 상황 모음

07딜러나 실차에서 직접 확인할 항목

공개 자료만으로는 국내 사양에서 되는지 단정하기 어려운 것들입니다. 서비스센터나 영업사원에게 물어보시면 확실합니다.

  1. '차선 변경 보조'가 경고 기능인지, 방향지시등만으로 자동 차선변경까지 되는지 — 주행 보조 → 주행 메뉴에 항목이 있는지 확인
  2. 티맵 기반 순정 내비의 무료 제공 기간과 이후 유료 전환 여부
  3. 갤럭시 폰으로 디지털 키 플러스(UWB, 주머니에 넣고 접근)가 실제로 동작하는지 — 아이폰은 대체로 됩니다
  4. 리모트 엔진 스타트가 내 차 하드웨어에 적용 가능한지, 무료 체험 기간과 가격
  5. 리모트 3D 뷰가 기본 포함인지 별도 구독인지
  6. 신차 커넥티드드라이브 기본 계약 기간(개월)
  7. 내 트림에 메모리 시트·3존 공조가 들어갔는지
  8. 차선이탈 경고·전방 충돌 경고 설정이 시동 후에도 유지되는지 (하루 껐다 다음날 확인해보면 바로 압니다)
