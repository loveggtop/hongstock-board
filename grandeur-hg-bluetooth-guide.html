1먼저 내 차 단말기가 어떤 사양인지 확인

2011~2012년식 그랜저 HG는 출고 옵션에 따라 화면이 3종류입니다. 메뉴 이름이 조금씩 달라서 이것부터 구분해야 합니다.

A 타입

순정 8인치 내비게이션

센터패시아 상단에 큰 터치 화면. 주변에 NAVI · MEDIA · PHONE · SETUP 하드키와 조그다이얼이 있음. HG300 로얄/노블 등 상위 트림에 다수.

B 타입

모니터형 오디오 (내비 없음)

화면은 있는데 지도 안내가 없는 사양. SETUP · PHONE 키는 그대로 있어서 조작 방법은 A 타입과 거의 동일.

C 타입

일반 오디오 (소형 LCD)

터치 화면 없이 라디오 주파수만 나오는 좁은 디스플레이. 블루투스 핸즈프리는 되지만 조작은 조그다이얼로만 함.

A · B 타입이면 2장과 3장을, C 타입이면 4장을 보세요. A와 B는 화면 메뉴가 사실상 같습니다. C 타입은 터치가 없어서 방식이 다릅니다.

2등록된 휴대폰 삭제하기

A · B 타입 기준. 새 폰을 등록하기 전에 기존 등록 정보를 지우는 것이 가장 확실한 방법입니다.

왜 삭제부터 하나요? HG 세대 블루투스 모듈은 최대 5대까지만 저장되고, 목록이 가득 차면 신규 등록 자체가 시작되지 않습니다. 또 예전에 연결됐던 폰 정보가 남아 있으면 단말기가 계속 그 폰만 찾으려고 해서 새 폰이 안 붙습니다.

시동 ON · P단 정차›SETUP›전화›블루투스 연결›기기 목록›삭제
  1. 차를 세우고 시동을 켭니다 반드시 P단 · 정차 상태여야 합니다. 주행 중에는 안전 규정 때문에 블루투스 등록·삭제 메뉴가 통째로 잠겨서 눌러도 반응이 없습니다. 이걸 몰라서 "고장났다"고 오해하는 경우가 가장 많습니다.
  2. SETUP 버튼을 누릅니다 화면 우측 또는 하단의 물리 버튼입니다. 설정 화면이 뜨면 상단 탭에서 전화(또는 Phone)를 고릅니다. 일부 연식은 PHONE 버튼을 누른 뒤 화면 안의 설정을 눌러도 같은 곳으로 들어갑니다.
  3. "블루투스 연결" 또는 "휴대폰 연결"을 선택 현재 등록된 기기 목록이 뜹니다. 전 차주의 폰 이름이나 예전에 쓰던 폰 이름이 그대로 남아 있는 경우가 흔합니다.
  4. 지울 기기를 선택하고 삭제를 누릅니다 목록에서 기기 이름을 한 번 탭하면 연결 / 연결해제 / 삭제 버튼이 나타납니다. 삭제 → 예를 누르면 끝입니다. 아무것도 안 남기고 새로 시작하려면 등록된 기기를 전부 지우세요.
  5. 휴대폰에서도 반드시 지웁니다 이 단계를 빼먹으면 재등록이 거의 실패합니다. 폰의 설정 → 블루투스 → 등록된 기기 목록에서 HYUNDAI / GRANDEUR / CARKIT 같은 이름을 찾아 연결 해제(등록 해제·이 기기 삭제) 하세요. 양쪽 다 지워야 완전히 초기화된 상태가 됩니다.
삭제하면 같이 사라지는 것 해당 폰으로 내려받았던 전화번호부와 통화 기록도 함께 지워집니다. 재등록하면 다시 내려받으니 문제는 없지만, 연락처가 수천 건이면 동기화에 몇 분 걸립니다.

3새 휴대폰 등록하기

음성 안내를 전혀 쓰지 않고 화면 터치만으로 진행합니다.

SETUP›전화›블루투스 연결›추가 / 신규등록›폰에서 검색›0000
  1. 휴대폰 블루투스를 먼저 켭니다 설정 → 블루투스 ON. 화면을 켜 둔 채로 두세요. 화면이 꺼지면 일부 안드로이드 폰은 검색 대상에서 빠집니다.
  2. SETUP → 전화 → 블루투스 연결로 들어갑니다 삭제할 때와 같은 화면입니다.
  3. 추가 / 신규 등록 / 기기 추가 버튼을 누릅니다 화면에 "휴대폰에서 검색하십시오" 안내와 함께 기기 이름과 인증번호가 표시됩니다. 이 대기 상태는 보통 2~3분 유지되니 그 안에 폰 조작을 마쳐야 합니다.
  4. 폰의 블루투스 검색 목록에서 차량을 선택 이름은 보통 HYUNDAI, GRANDEUR, CARKIT, HandsFree 중 하나입니다. 화면에 표시된 이름과 같은 것을 고르세요.
  5. 인증번호 0000 입력 또는 숫자 일치 확인 구형 방식은 폰에 0000(경우에 따라 1234)을 직접 입력합니다. 최신 폰이면 양쪽 화면에 같은 6자리 숫자가 뜨고 확인만 누르면 됩니다.
  6. 폰에 뜨는 연락처·통화기록 접근 허용을 승인 이걸 거절하면 통화는 되는데 전화번호부가 안 뜨는 상태가 됩니다. 나중에 폰의 블루투스 기기 상세 설정에서 다시 켤 수 있습니다.
  7. 연결 확인 단말기 화면 상단에 블루투스 아이콘이 뜨고, PHONE 버튼을 눌렀을 때 전화번호부와 최근 통화 목록이 보이면 정상입니다. 음악을 재생해 스피커로 나오는지도 확인해 보세요.
등록 성공률을 크게 올리는 3가지 ① 차 안에 다른 블루투스 기기(블랙박스, 이어폰, 다른 가족 폰)의 전원을 잠시 꺼 둘 것 ② 폰을 단말기에서 1m 이내로 가까이 둘 것 ③ 한 번 실패하면 곧바로 재시도하지 말고 폰 블루투스를 껐다 켠 뒤 다시 시작할 것.

4화면 없는 일반 오디오(C 타입)일 때

터치 화면이 없으면 조그다이얼과 물리 버튼으로 같은 메뉴에 들어갑니다.

  1. SETUP 버튼을 누릅니다 좁은 LCD에 설정 항목이 한 줄씩 표시됩니다.
  2. 조그다이얼을 돌려 Phone / 블루투스 항목을 찾습니다 다이얼을 눌러 선택합니다. 항목 이름은 Bluetooth, Pairing, 휴대폰 연결 등으로 표기됩니다.
  3. 하위 메뉴에서 Pair(등록) 또는 Delete(삭제)를 고릅니다 등록을 고르면 검색 대기 상태가 되고, 삭제를 고르면 등록된 기기 이름이 순서대로 표시됩니다. 지울 기기에서 다이얼을 길게 누르거나 확인을 누르면 삭제됩니다.
  4. 폰에서 검색 → 선택 → 0000 입력 이후는 3장과 동일합니다.
C 타입에서 SETUP에 전화 메뉴가 아예 없다면 그 차는 블루투스 핸즈프리 미장착 사양일 수 있습니다. 이 경우 핸들에 통화(수화기) 버튼이 있는지 확인해 보세요. 통화 버튼이 없으면 하드웨어가 없는 것이라 메뉴로 해결되지 않습니다.

5음성인식이 정말 고장인지 자가 진단

블루투스 등록은 위 방법으로 해결되지만, 음성인식 자체가 왜 안 되는지도 나눠서 볼 수 있습니다.

증상추정 원인대응
핸들 음성인식 버튼을 눌러도 "삐" 소리조차 안 남핸들 리모컨 스위치 접점 불량, 클럭 스프링, 배선 단선다른 핸들 버튼(볼륨·채널)은 되는지 먼저 확인. 다른 버튼도 다 안 되면 클럭 스프링 쪽
"삐" 소리는 나는데 말을 못 알아들음마이크 불량 또는 마이크 배선 접촉 불량통화할 때 상대방이 내 목소리를 듣는지 확인
통화 시 상대방이 내 목소리를 못 들음마이크 고장 확정오버헤드 콘솔(룸미러 부근) 마이크 교체. 부품값 자체는 비싸지 않은 편
통화는 잘 되는데 음성인식만 안 됨음성인식 엔진·소프트웨어 문제, 또는 인식률 저하단말기 리셋 후 재시도. 안 되면 서비스센터 진단
블루투스 아이콘도 안 뜨고 전화 메뉴 전체가 먹통블루투스 모듈 자체 불량모듈 교체 필요. 이 경우 등록 절차로는 해결 불가
핵심 음성인식이 고장이어도 블루투스 등록·삭제는 화면 메뉴만으로 100% 가능합니다. 음성인식은 편의 기능일 뿐 등록의 필수 경로가 아닙니다. 다만 마이크가 고장이면 등록에 성공해도 핸즈프리 통화 시 상대가 내 말을 못 듣습니다. 등록 후 반드시 통화 테스트를 해 보세요.

6단말기 리셋 / 초기화 방법

메뉴가 반응이 없거나 등록 대기 화면에서 멈출 때 순서대로 시도합니다.

1단계 — 단말기 리셋 (가장 가벼움)

  • 단말기 전면 또는 조그다이얼 주변의 바늘구멍(RESET)을 클립·이쑤시개로 3초 정도 누릅니다.
  • 구멍이 안 보이면 전원 노브를 10초 이상 길게 누르거나, MAP + SEEK를 동시에 길게 누르는 조합이 먹히는 연식도 있습니다.
  • 저장된 설정과 등록 기기는 대부분 유지됩니다.

2단계 — 시동 완전 껐다 켜기

  • 시동을 끄고 운전석 문을 열었다가 닫은 뒤 5분 정도 두면 단말기가 완전히 슬립에 들어갑니다. ACC만 껐다 켜는 것과는 다릅니다.

3단계 — 배터리 단자 분리 (최후)

  • 보닛을 열고 배터리 (−) 단자만 분리, 10분 뒤 재결합합니다.
  • 블루투스 모듈까지 완전 초기화되어 잔여 페어링 정보가 지워집니다.
배터리 분리 전 반드시 확인 라디오 프리셋·시계·트립 정보가 초기화되고, 차종에 따라 오토 윈도우(원터치 상승) 초기화가 필요해집니다. 재연결 후 각 창문을 끝까지 올린 상태로 스위치를 3초 더 당겨 학습시켜 주세요. 블랙박스 상시전원 설정도 다시 확인하시고요. 자신 없으면 이 단계는 건너뛰고 서비스센터를 이용하는 편이 낫습니다.

8작업 전 최종 체크리스트

이 순서대로만 하면 대부분 해결됩니다.

  • 시동 ON, 기어 P단, 완전 정차 상태인가
  • 단말기에서 등록된 기기를 전부 삭제했는가
  • 휴대폰에서도 차량 기기 등록을 해제했는가
  • 단말기 리셋을 한 번 해줬는가
  • 차 안의 다른 블루투스 기기 전원을 껐는가
  • 휴대폰 블루투스가 켜져 있고 화면이 켜진 상태인가
  • 단말기에서 추가를 누른 직후 2~3분 안에 폰 조작을 마쳤는가
  • 인증번호 0000을 입력했거나 숫자 일치를 확인했는가
  • 폰의 연락처 접근 허용을 승인했는가
  • 등록 후 통화 테스트로 상대방이 내 목소리를 듣는지 확인했는가
여기까지 다 해도 안 될 때 블루투스 모듈이나 마이크 하드웨어 고장일 가능성이 높습니다. 현대 블루핸즈에서 진단받거나, 연식을 고려해 안드로이드 올인원 매립으로 헤드유닛을 통째로 바꾸는 것도 실제로 많이 선택하는 대안입니다. 최신 폰 연동과 화면 크기 문제까지 한 번에 해결됩니다.
